# VoteApp — Java

A console-based voting application built in Java. A reimplementation of the same system also built in Python — demonstrating the same core logic across two different languages.

Built as part of ISC Class 12 Computer Science coursework and deployed for actual school use — recognised with the **Effort and Effectiveness Award**.

## Features

- Candidate registration
- Vote casting with duplicate-vote prevention
- Vote tallying and result display
- Console-based interface

## How to Run

**Requirements:** Java 8+, IntelliJ IDEA (or any Java IDE)

```bash
# Clone the repo
git clone https://github.com/darshfi/VoteApp-using-java.git
```

Open the project in IntelliJ IDEA → navigate to `src/` → run the main class.
